## 一句话理解 Transformer

Transformer 干的事：**给一串输入（比如一句话），预测下一个最可能的输出（下一个词）**。它是现在所有大模型（GPT、Claude、文心等）的底层架构。

核心突破点就一个词：**注意力机制（Attention）**——让模型在处理一个词时，能"回头看"整句话里哪些词跟它最相关。

---

## 一、词向量 Embedding：让计算机理解文字

计算机只认数字。第一步是把词变成一串数字（向量），叫 **Embedding（词向量）**。

- 就像给每个词分配一个"多维坐标"，比如 256 维、768 维的 `float[]`。
- 语义相近的词，坐标也接近。`"国王" - "男" + "女" ≈ "女王"`，这种向量运算真的能算出来。

```
"猫"   -> [0.2, -0.7, 0.1, ...]   // 一个 float 数组
"狗"   -> [0.3, -0.6, 0.2, ...]   // 和"猫"很接近，因为都是动物
"银行" -> [-0.9, 0.4, 0.8, ...]   // 离得很远
```

> **后端类比**：把每个词做了一次特征化的 HashMap 映射，value 是一个高维数组。

---

## 二、位置编码 Positional Encoding：解决顺序问题

问题："狗咬人" 和 "人咬狗" 用的词一样，但意思相反。光有词向量，模型不知道谁在前谁在后。

解决办法：给每个词的向量再**叠加一个"位置信息"**。

> **后端类比**：就像数据库里一条记录除了内容，还带一个 `index` 字段。

为什么要专门做这个？因为 Transformer 不像老的 RNN 那样一个字一个字顺序读，它是**一次性并行读入整句话**（这也是它快的原因），所以必须额外告诉它顺序。

## 三、核心：注意力机制 Self-Attention

这是整个架构的灵魂。用一个例子：

> "小明把水倒进杯子里，因为**它**太满了。"

"它"指的是杯子还是水？靠 Attention——处理"它"这个词时，去计算"它"和句子里**每个词的相关度**，发现和"杯子"相关度最高，就重点参考"杯子"的信息。

### QKV 模型

每个词会生成 3 个向量，这套设计很像**检索系统**：

| 概念 | 类比（搜索引擎/数据库） |
|------|------------------------|
| **Query（查询）** | 我要查什么（相当于搜索关键词） |
| **Key（键）** | 每条数据的索引标签（相当于 DB 索引） |
| **Value（值）** | 每条数据的实际内容 |

流程和一次"查询-匹配-取值"几乎一模一样：
1. 用当前词的 **Query** 去和所有词的 **Key** 做匹配，算出相关度分数（点积）。
2. 分数归一化成权重（Softmax，加起来=100%）。相关度高的权重大。
3. 按权重把所有词的 **Value** 加权求和 —— 得到这个词"融合了上下文之后"的新表示。

```
处理"它"时：
  它·杯子 = 0.7   （权重70%）
  它·水   = 0.2   （权重20%）
  它·小明 = 0.1   （权重10%）
  -> "它"的新向量 = 0.7*杯子 + 0.2*水 + 0.1*小明
```

**这就是"注意力"——每个词都会根据相关度，从全句里"抓取"对自己有用的信息。**

## 四、QKV 计算细节（带数字走一遍）

### QKV 是怎么"生出来"的

每个词的 Embedding 向量 `x`，分别乘以三个**训练出来的权重矩阵**，得到 Q、K、V：

```
Q = x · Wq     // Query
K = x · Wk     // Key
V = x · Wv     // Value
```

- `Wq、Wk、Wv` 是模型训练出来的参数（"大模型权重"的一部分），训练完固定。
- 同一个词向量 `x`，过三个不同矩阵，得到三个不同用途的向量。

### 完整算例

设：向量维度 = 2，句子 = "我 爱 猫"。

**第0步：三个词的向量**
```
我  x1 = [1, 0]
爱  x2 = [0, 1]
猫  x3 = [1, 1]
```

**第1步：乘权重矩阵得到 Q/K/V**（此处用单位矩阵便于演示，真实为训练值）
```
      Q       K       V
我  [1,0]   [1,0]   [1,0]
爱  [0,1]   [0,1]   [0,1]
猫  [1,1]   [1,1]   [1,1]
```

**第2步：算注意力分数（Q 点积 K）** —— 以"爱"为例
```
爱的Q = [0,1]
score(爱→我) = [0,1]·[1,0] = 0
score(爱→爱) = [0,1]·[0,1] = 1
score(爱→猫) = [0,1]·[1,1] = 1
```
> 点积越大 = 越相关。这就是**向量相似度**，和推荐系统里算 cosine 相似度一回事。

**第3步：缩放（Scaled）** —— 除以 `√d`（d=2）
```
0/√2 = 0,   1/√2 ≈ 0.707,   1/√2 ≈ 0.707
```
> 为什么除？维度越高点积越大，会导致 Softmax 后梯度太小难训练。除以 `√d` 把数值拉回稳定范围。

**第4步：Softmax 归一化成权重**
```
softmax([0, 0.707, 0.707]) ≈ [0.20, 0.40, 0.40]
```
含义：处理"爱"时，20% 参考"我"，40% 参考"爱"，40% 参考"猫"。

**第5步：按权重加权求和 V**
```
输出(爱) = 0.20*[1,0] + 0.40*[0,1] + 0.40*[1,1] = [0.60, 0.80]
```
`[0.60, 0.80]` 就是"爱"融合上下文后的新表示。对每个词都做一遍，就是这层 Attention 的输出。

### 公式总览

```
Attention(Q, K, V) = softmax( Q·Kᵀ / √d ) · V
```
- `Q·Kᵀ` → 算所有词两两相关度（N×N 矩阵）
- `/√d` → 缩放
- `softmax(...)` → 归一化成权重
- `... · V` → 按权重聚合内容

### 伪代码（后端视角）

```java
// 输入：句子里 N 个词的向量, 每个维度 d
float[][] X;   // [N][d]

// 1. 线性变换得到 Q K V（Wq/Wk/Wv 是训练好的参数）
float[][] Q = matmul(X, Wq);  // [N][d]
float[][] K = matmul(X, Wk);
float[][] V = matmul(X, Wv);

// 2. 算分数矩阵 scores[i][j] = 词i对词j的相关度
float[][] scores = matmul(Q, transpose(K)); // [N][N]

// 3. 缩放
for (i,j) scores[i][j] /= Math.sqrt(d);

// 4. 每一行做 softmax -> 权重
for (int i = 0; i < N; i++) scores[i] = softmax(scores[i]);

// 5. 加权求和 V
float[][] output = matmul(scores, V); // [N][d]
```

整个过程就是 **3 次矩阵乘法 + 1 次 softmax**，无循环依赖，所有词并行算完——这就是它比 RNN（串行）快的根本原因。

## 五、多头注意力 Multi-Head

### 为什么要多头

单个 Attention 只能学一种关注模式。但一句话里的关系是多维度的：

> "小明昨天在图书馆借的那本书很好看"

理解"书"时同时在关注：谁的书（小明）、什么时候（昨天）、在哪（图书馆）、怎么样（好看）。一个头顾不过来，所以搞多个头，每个头专注一种关系，最后合并。

> **后端类比**：同一份数据建多个不同维度的索引，查询时多路并行，再汇总。

### 核心机制：把向量"切分"给各个头

多头**不是**把维度变大，而是**把原维度切成几段，每段给一个头**，总计算量基本不变。

设 `d=8`，头数 `h=2`，每头分到 `d/h=4` 维：
```
"猫"的向量 (8维):
[ a1, a2, a3, a4 | b1, b2, b3, b4 ]
  └──── 头1 (4维) ──┘ └──── 头2 (4维) ──┘
```

### 流程

**第1步：每个头独立生成自己的 Q/K/V**（各头有独立参数矩阵）
```
头1:  Q1 = X·Wq1   K1 = X·Wk1   V1 = X·Wv1    // [N × 4]
头2:  Q2 = X·Wq2   K2 = X·Wk2   V2 = X·Wv2    // 另一套参数
```

**第2步：每个头独立并行跑一遍完整 Attention**
```
Z1 = Attention(Q1, K1, V1)   // [N × 4]  比如学"指代关系"
Z2 = Attention(Q2, K2, V2)   // [N × 4]  比如学"时间关系"
```

**第3步：拼接（Concat）回原长度**
```
[ z1,z2,z3,z4 ] [ z5,z6,z7,z8 ] → [z1..z8]   // 简单数组拼接，无计算
```

**第4步：过输出矩阵 Wo 融合**
```
最终输出 = Concat(Z1, Z2) · Wo    // [N × 8]
```

### 数据流图

```
                输入 X [N × d=8]
                     │
     ┌───────────────┴───────────────┐
     ▼                               ▼
   头1 (Wq1/Wk1/Wv1)              头2 (Wq2/Wk2/Wv2)
   投影成 4维                      投影成 4维
     │                               │
   Attention                      Attention     ← 两个头并行
   softmax(Q1K1ᵀ/√d)V1            softmax(Q2K2ᵀ/√d)V2
     │                               │
   Z1 [N × 4]                     Z2 [N × 4]
     └───────────────┬───────────────┘
                   Concat → [N × 8]
                     │
                   · Wo  (融合)
                     │
                最终输出 [N × 8]
```

### 容易混淆的点

| 疑问 | 答案 |
|------|------|
| 多头让向量变长了？ | **不是**。切分原维度给各头，总维度不变，算完拼回原长度 |
| 每个头一样吗？ | 不一样。每头有独立 Wq/Wk/Wv，学到不同关系 |
| 头之间互相影响吗？ | Attention 阶段完全独立并行，只在最后 Concat + Wo 时融合 |
| 为什么不用一个大头？ | 一个头只能学一种模式；多头能同时捕捉多种关系 |
| 计算量增加了吗？ | 基本没有，只是拆开算 |

> **一句话**：Multi-Head 本质是"分片并行处理 + 结果合并"，思路类似 MapReduce。

## 六、整体结构：像一条流水线

Transformer 把上述模块**堆叠很多层**（GPT 有几十上百层），逐层提炼语义：

```
输入文字
  → Embedding（转向量）
  → 加位置编码
  → ┌─────────────────────────┐
    │  多头注意力 (看上下文)     │   ← 重复 N 层
    │  前馈网络 (进一步加工)     │      每层都有残差连接 + 归一化
    └─────────────────────────┘
  → 输出层（预测下一个词的概率分布）
```

两个工程味很浓的细节：
- **残差连接（Residual）**：每层输出 = `输入 + 本层处理结果`。类比责任链里"原始数据一路透传，避免层数太深信息丢失"。
- **层归一化（LayerNorm）**：每层把数据缩放到稳定范围，防止数值爆炸/消失，类似数据标准化。

## 七、它怎么"生成"回答（自回归）

生成是**一个词一个词循环产生**的：

```
输入："今天天气"
第1轮 -> 预测出 "真"
输入："今天天气真"
第2轮 -> 预测出 "好"
输入："今天天气真好"
第3轮 -> 预测出 [结束]
```

每一轮把已有的全部文字重新喂进去，预测下一个概率最高的词，拼上去再循环。这就是为什么大模型回答是**一个字一个字蹦出来**的。

## 八、后端视角类比总结

| Transformer 概念 | 后端类比 |
|------------------|---------|
| Embedding | 把对象序列化成特征向量（高维 `float[]`） |
| Positional Encoding | 记录顺序的 index 字段 |
| Attention (QKV) | 一次"按 Key 匹配、按权重取 Value"的检索聚合 |
| Multi-Head | 多个索引维度并行查询后合并（MapReduce 思路） |
| 多层堆叠 | 流水线 / 责任链，逐层加工 |
| 残差连接 | 原始数据透传，避免信息丢失 |
| 自回归生成 | 循环调用，每次基于历史预测下一步 |

### 最终一句话

**Transformer = Embedding（把词变向量）+ Attention（每个词按相关度从全文抓信息）+ 多层堆叠（逐层提炼）+ 自回归（一个词一个词地预测生成）。**

最该记住的是 **Attention**：它本质就是"**按相关度检索并加权聚合**"，只不过对象是句子里的每个词。抓住这一点，整个架构就通了。
